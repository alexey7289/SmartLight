* initApp - Главная функция импорта данных из файла настроек который описан в переменной settingsPath. По умолчанию это *'./config/settings.json'*
* logWarnRender - Функция вывода warning-сообщений в консоль браузера для функций отвечающих за рендер.
* renderIsPower - Функция отрисовки FAB (Floating Action Button). При включении/выключении функции меняется атрибут *variable=""* и меняется иконка lightbulb/light_off
