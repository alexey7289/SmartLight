## ***app.js*** (Описание функций + чек-лист)

### Root
* *Root-функции* проверка наличия имопртируемых данных. При отсутствии возвращает `false` и дальнейшее выполнение `app.js` прекращается.
    * ***validateDOMElements()*** — функция проверки наличия всех необходимых DOM-элементов на странице. Находит элементы по ID и **сохраняет ссылки в глобальные переменные**. Возвращает `true`, если все элементы найдены, или `false`, если хотя бы один отсутствует.
|Функция						|Описание									|Вызывается						|Возвращает					|
|:------------------------------|:------------------------------------------|:------------------------------|:--------------------------|
|`validateDOMElements()`		|Проверка необход. DOM-элементов			|1 раз при старте				|`boolean`					|



### Init
* *Init-функции* парсинг данных.
    * ***initApp()*** — асинхронная функция инициализации приложения. Загружает файл настроек `settings.json` (путь хранится в `settingsPath`), парсит `JSON` и сохраняет результат в глобальную переменную `currentSettings`. При ошибке загрузки (HTTP-ошибка или сетевой сбой) выводит сообщение в консоль и прерывает выполнение.
|Функция						|Описание									|Вызывается						|Возвращает					|
|:------------------------------|:------------------------------------------|:------------------------------|:--------------------------|
|`initApp()`					|Загрузка данных							|1 раз при старте				|`promise<void>`			|


### Utilities
* *Utilities-функции* вспомогательные функции, которые используются в разных местах.
    * ***addLog(message, isError)*** — функция добавления сообщения в окно логирования. Форматирует текст с временной меткой и префиксом `[INFO]` (по умолчанию) или `[ERROR]` (если `isError = true`), добавляет новую строку к существующему логу. Если поле лога (`logField`) не найдено, функция завершается без действий.
|Функция							|Описание									|Вызывается						|Возвращает					|
|:----------------------------------|:------------------------------------------|:------------------------------|:--------------------------|
|`addLog()`							|Добавление сообщения в окно логирования	| Везде							| `void`					|



### Master
* *Master-функция* — центральный оркестратор. Вызывает все Check-функции и обновляет глобальное состояние UI.
    * ***syncUI()*** — центральная функция, которая запускает все Check-функции, собирает результаты валидации и обновляет глобальное состояние интерфейса (видимость полей, состояние кнопок). Вызывается при старте или при изменении данных.
|Функция							|Описание									|Вызывается						|Возвращает					|
|:----------------------------------|:------------------------------------------|:------------------------------|:--------------------------|
|`syncUI()`							|Запускает все проверки и обновляет интерф. |При старте + input/select		|`void`						|



### Render
* *render-функции* отображают только данные. Они не проверяют валидность, не управляют кнопками, не логируют ошибки. Их задача — взять значение из `currentSettings` и показать в UI.
|Функция						|Описание									|Вызывается						|Возвращает					|
|:------------------------------|:------------------------------------------|:------------------------------|:--------------------------|
|`renderVersion()`				|Версия веб-сервера							|1 раз при старте				|`void`						|
|`renderIsPower()`				|Состояние кнопки питания					|При старте + при change		|`void`						|
|`renderIsDark()`				|Состояния toggle темной темы				|При старте + при change		|`void`						|
|`renderFieldDimsX()`			|Поле размера `X`							|1 раз при старте				|`void`						|
|`renderFieldDimsY()`			|Поле размера `Y`							|1 раз при старте				|`void`						|
|`renderFieldDimsA()`			|Поле размера `A`							|1 раз при старте				|`void`						|
|`renderFieldDimsB()`			|Поле размера `B`							|1 раз при старте				|`void`						|
|`renderFieldPixelSize()`		|Поле размера пикселя						|1 раз при старте				|`void`						|
|`renderSelectPatternId()`		|Поле выбора `patternId` 					|При старте + при change		|`void`						|



### Valid
* *valid-функции* - математика и вычисления. Управляют состоянием `UI-функций`.
|Функция						|Описание									|Вызывается						|Возвращает					|
|:------------------------------|:------------------------------------------|:------------------------------|:--------------------------|
|`isDimsXValid()`				|Проверка кратности DimsX к pixelSize 		| При старте + при input 		|`boolean`					|
|`isDimsYValid()`				|Проверка кратности DimsY к pixelSize 		| При старте + при input 		|`boolean`					|
|`isDimsAValid()`				|Проверка кратности DimsA к pixelSize 		| При старте + при input 		|`boolean`					|
|`isDimsBValid()`				|Проверка кратности DimsB к pixelSize 		| При старте + при input 		|`boolean`					|



### UI
* *UI-функции* - это процесс изменения внешнего вида элементов в зависимости от логики, валидации или правил приложения.
|Функция						|Описание									|Вызывается						|Возвращает					|
|:------------------------------|:------------------------------------------|:------------------------------|:--------------------------|
|`uiStateDimsX()`				|Статус поля DimsX на основе флага isValid	| При старте + при input		|`void`						|
|`uiStateSaveButton()` 			|Статус кнопки "Сохранить" 					| При input 					|`void` 					|



### Check
* *check-функции* - связывает Valid и UI-функции.
|Функция						|Описание									|Вызывается						|Возвращает					|
|:------------------------------|:------------------------------------------|:------------------------------|:--------------------------|
|`checkDimsX()`					|Проверяет DimsX и обновляет UI поля 		|При старте + `syncUI()` 		|`boolean` 					|



### Listeners
* *listeners-функции* - 
|Функция						|Описание									|Вызывается						|Возвращает					|
|:------------------------------|:------------------------------------------|:------------------------------|:--------------------------|
|`dimsXListener()`				|Слушатель полей ввода размеров				|При input 						|`viod`						|
|`patternIdListener()`			|Слушатель выпадающего списка `patternId`	|При select						|`void`						|





* ***toggleExtraDims()*** — функция переключения видимости полей `DimsA` и `DimsB`. Если `patternID > 3`, поля отображаются, иначе скрываются. Возвращает `true`, если поля показаны, `false` — если скрыты или элементы не найдены.











* ***logWarnRender()*** - вывод warning-сообщений в консоль браузера для функций отвечающих за рендер.

* ***renderIsPower()*** - отрисовка `FAB` (Floating Action Button). При включении/выключении функции меняется атрибут `variable=""` и меняется иконка `lightbulb/light_off`.
* ***checkDimsXDivisibility()*** - функция проверки делимости поля размера "X" на размеры из поля "Размер кластера". Возвращает `true` если  делится без остатка.


## ***styles.css***
* ***--md-fab-icon-size: 36px;*** - размер иконки `FAB`. По умолчанию - `24px`.
